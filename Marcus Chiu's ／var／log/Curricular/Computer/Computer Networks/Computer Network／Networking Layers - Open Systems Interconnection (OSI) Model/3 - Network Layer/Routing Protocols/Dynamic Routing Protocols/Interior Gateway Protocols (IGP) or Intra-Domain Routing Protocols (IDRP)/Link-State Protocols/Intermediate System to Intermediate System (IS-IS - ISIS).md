###### Intermediate System to Intermediate System (IS-IS - ISIS)
````excerpt
- is a [[Routing Protocols|routing protocol]] designed to move information efficiently within a computer network, a group of physically connected computers, or similar devices
- it accomplishes this by determining the best route for data through a packet-switched network
````
