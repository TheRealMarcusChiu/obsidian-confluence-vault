<strong>Run A and then B, regardless of the success or failure of A</strong>
<span style="white-space: pre-wrap"><code>  A ; B </code></span>

<strong>Run B only if A succeeded</strong>
<span style="white-space: pre-wrap"><code>  A && B </code></span>

<strong>Run B only if A failed</strong>
<span style="white-space: pre-wrap"><code>  A || B </code></span>
